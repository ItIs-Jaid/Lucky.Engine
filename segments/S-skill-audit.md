# S-skill-audit — PRE-LOOP

**Purpose** — never add a skill that duplicates one already loaded.

## Do
1. Search the pool for the same trigger words.
2. If one exists, patch it. Two skills with one trigger is a routing bug.
3. Check the last-load evidence: an unused skill is a cheaper delete than a rewrite.
4. Decide: patch, merge, or create. State which and why.

## Gate
Decision is patch, merge, or create, with the overlapping skill named.
