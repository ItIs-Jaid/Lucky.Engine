# S-skill-test — LOOP BODY

**Purpose** — prove the skill runs before it enters the pool.

## Do
1. Load it as a fresh agent would: `skill_view(name)`.
2. Execute step 1 with only what the skill provides.
3. Note every point where you had to guess. Each guess is a missing line.
4. Fix the skill, not the run.

## Gate
Step 1 executes with zero guesses and the load is evidenced.
