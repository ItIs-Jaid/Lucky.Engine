# S-detection-gap — MIDDLE

**Purpose** — find what would be missed, not what is already covered.

## Do
1. For each crown jewel: state the attack path in one sentence.
2. Check whether a detection exists. Cite the rule, log source, or alert.
3. Rank gaps by likelihood x impact, not by tool enthusiasm.
4. Verify each claimed detection by triggering it in a lab.

## Gate
gaps_enumerated == crown_jewels * plausible_paths, each with evidence.
