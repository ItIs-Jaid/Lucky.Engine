# S-source-discovery — PRE-LOOP

**Purpose** — build the candidate pool before judging any of it.

## Do
1. Run 3 distinct queries: the plain terms, the expert terms, the adversarial terms.
2. Collect 10-15 candidates with url, publisher, date.
3. Include one source that argues the opposite.
4. Do not read deeply yet. Discovery and triage are separate phases.

## Gate
Pool size >= 10 with at least one contrarian source.
