# S-context-pack — START

**Purpose** — hand the next step only the context it needs. Never the whole corpus.

## Do
1. Restate the root goal in one sentence (max 20 words).
2. List the 3 facts that change the decision. Drop everything else.
3. Name the artifact this chain must produce and where it lands.
4. Name what is explicitly out of scope.

## Gate
Context pack is <= 350 tokens and contains zero background prose.

## Output
```
goal: <one sentence>
facts: [f1, f2, f3]
artifact: <path or type>
out_of_scope: [..]
```
