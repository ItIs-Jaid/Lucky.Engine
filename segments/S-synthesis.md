## Do
1. Lead with the answer, then the evidence, then the caveats.
2. One decision or recommendation. Not a menu.
3. State the falsifier: what would prove this wrong.
4. Write the artifact to disk. Do not report it in chat only.

## Gate
Root is done only when the artifact exists, is cited, and names its falsifier.

## Output
```
artifact: report.md
answer: <3 sentences>

open_questions: [..]
```
