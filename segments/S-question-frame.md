# S-question-frame — PRE-LOOP

**Purpose** — a research loop only converges if the question is falsifiable.

## Do
1. Restate the ask as one answerable question.
2. Name the decision it feeds. No decision -> stop, this is curiosity not work.
3. Write the disconfirming evidence you would accept.
4. Set the stopping rule: how many sources, how much time, what precision.

## Gate
Question is answerable with public evidence and has an explicit stopping rule.
