# S-threat-model — PRE-LOOP

**Purpose** — enumerate paths before hunting detections.

## Do
1. For each crown jewel: who wants it, what access reaches it.
2. Write paths as: initial access -> pivot -> objective.
3. Mark which paths are already instrumented.
4. Rank by likelihood x impact, not by novelty.

## Gate
Every crown jewel has >= 2 written paths.
